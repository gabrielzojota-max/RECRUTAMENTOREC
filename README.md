# REC Cidade Grande

Painel de recrutamento da equipe REC: gerador de Controle Staff/Registro REC, histórico, metas e gestão de contas.

## Stack
- React + TypeScript + TanStack Start
- Supabase Auth + PostgreSQL + Row Level Security
- Vercel para hospedagem

## Segurança e publicação
A aplicação ainda está em migração. Não conecte um domínio público nem convide membros antes de concluir `docs/DEPLOYMENT.md`, aplicar as migrations, configurar as variáveis secretas no dashboard da Vercel e executar os testes de autorização. O site Lovable antigo não é alterado por este repositório.

Consulte `docs/DEPLOYMENT.md` para a configuração inicial e `supabase/migrations` para o esquema do banco.
